# FileBeam Lite (极简局域网互传 · 免费开源版)

FileBeam Lite 是专为 PC 与手机跨设备局域网文件互传设计的极简免安装工具。  
电脑端一键启动服务，手机端无需下载任何 APP，扫描屏幕二维码通过浏览器即可实现双向秒速传输。

---

## 🌟 核心特性

- **手机端零安装**：任意品牌安卓手机（华为、小米、OPPO、vivo等）或 iPhone 均免装应用，扫码即用。
- **纯局域网传输**：基于内网直连通道，数据不经过任何第三方公网服务器，保护个人与工作隐私。
- **无外网亦可用**：只要连接同一无线路由器，即使宽带断开或无互联网也能高速互传。
- **10MB 免费额度**：完美覆盖日常拍照原图（3MB~7MB）、PDF 合同、Word 文档、发票音频传输。
- **清晰升级引导**：内置专业版（FileBeam Pro）无缝升级通道，满足大文件与商业场景需求。

## 🚀 快速使用指南

### 1. 启动服务
- **Windows 用户**：双击运行 `启动FileBeam_Lite.bat` 即可自动启动并弹出浏览器。
- **命令行启动**：
  ```bash
  pip install -r requirements.txt
  python server.py
  ```

### 2. 手机连接
1. 确保手机与电脑连接至**同一个 WiFi 路由器**（或手机开启便携热点，电脑连接该热点）。
2. 使用手机自带相机、微信或任意浏览器扫描电脑屏幕上的二维码，即可自动进入传输页面。

### 3. 双向互传
- **手机发送到电脑**：在手机网页点击“选择文件”或拍照上传，电脑端的 `received` 文件夹将实时保存接收的文件。
- **电脑发送到手机**：将需要共享的文件直接复制到电脑端 `shared` 文件夹，手机刷新页面即可点击下载。

## 🎯 本软件相比 LocalSend 与 copyparty 的核心特色

### 1. 相比 LocalSend 的杀手级特色：
- **手机端“零安装、零阻力”**：
  LocalSend 最大的使用痛点是**接收方手机必须提前安装 APP**。在办公室给同事发文件、在家庭给长辈传照片、或者在临时借用的手机上，要求对方去应用商城搜软件安装往往费时费力。
  **FileBeam 做到真正的“无感互传”**：只要用手机自带相机扫一眼电脑二维码，直接在网页上收发，用完即走，没有丝毫心理负担。
- **无需复杂的局域网组播穿透**：
  LocalSend 依赖 UDP 组播寻找设备，在很多开启了“AP 隔离”或禁用组播的企业网络、合租 WiFi 下经常互相搜不到设备；而 FileBeam 基于标准的 HTTP/WebSocket 协议，只要 IP 能通就能 100% 连上。

### 2. 相比 copyparty 的核心特色：
- **专为“手机电脑日常互传”定制的极简心智**：
  copyparty 是一个极其强大硬核的 Python 文件服务器兼媒体网盘，拥有数百个命令行参数、权限系统、音视频播放器与转码功能，更偏向**极客与运维工程师**搭建个人私有云；
  而普通用户只想**“把手机里的几张照片快速导到电脑”**或**“把电脑文档发到手机”**。copyparty 界面类似传统的目录索引树，手机操作非常吃力。
  **FileBeam 做了极致的场景降噪**：
  - 明确划分“📤 接收区”与“📁 共享区”；
  - 自动将电脑 IP 生成自适应二维码展示在屏幕中央；
  - 专门针对手机移动端做了大按钮与滑动卡片适配，老少皆宜。

### 3. 面向移动端大文件的特色保障（Pro 版特权）：
- **Screen Wake Lock（屏幕常亮锁）**：手机浏览器传大文件最怕熄屏中断，FileBeam 自动锁定手机屏幕防止锁屏断流。
- **针对手机下载限制的“一键全部接收”**：手机移动浏览器对多弹窗下载有极其严格的安全拦截，FileBeam 独创了防拦截的毫秒级时序队列下载，并在服务端提供瞬时流式 ZIP 打包。

## 💎 专业版 (FileBeam Pro) 差异与预留链接

免费版定位为日常轻量文件互传利器；如需处理视频剪辑、大型安装包或团队办公，可平滑升级至专业版：

- **无文件大小限制**：支持数百 MB 到数十 GB 超大文件。
- **分块抗弱网传输**：智能动态分块与断点续传，网络波动自动重试。
- **屏幕防休眠唤醒锁**：手机传输期间保持常亮，防止后台休眠中断。
- **批量接收与流式打包**：一键连续下载，或在服务端实时打包为 ZIP。
- **传输日志生命周期**：支持 24小时 / 3天 / 7天 / 会话级自动清理日志。

> **升级链接配置说明**：  
> 官方网站部署上线后，直接在 `config.json` 中的 `pro_upgrade_url` 字段填入正式网址即可全端生效。

```text
    ├── index.html         # 移动优先的自适应前端界面
    ├── css/style.css      # 现代卡片式响应式样式
    └── js/app.js          # 前端交互与 10MB 超限友好提示
```
