# Security Policy

FileBeam Lite is designed for transfer inside a trusted local network. Do not expose the service directly to the public internet.

## Reporting a vulnerability

Please avoid publishing secrets or exploitable details in a public issue. Report vulnerabilities privately to the repository owner with:

- affected version,
- reproduction steps,
- potential impact,
- any suggested mitigation.

## Safe deployment

- Use FileBeam Lite only on a trusted Wi-Fi or hotspot.
- Keep the operating system and Python dependencies updated.
- Review files before sharing them through the `shared` directory.
- Do not open the configured port in a public router or firewall rule.
